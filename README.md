# lbhongdafood.com

A complete, commercial-grade team website for **lbhongdafood.com** — a UK-based R&D studio focused on technology innovation, privacy-first design and immersive digital experiences.

## Project structure

```
lbhongdafood/
├── index.html              # Home page
├── services.html           # Services & products
├── advantages.html         # Team advantages
├── updates.html            # Releases, blog, design
├── contact.html            # Contact + form
├── privacy.html            # Comprehensive privacy policy
├── terms.html              # Terms of service
├── robots.txt              # Search engine directives
├── sitemap.xml             # XML sitemap
├── app-ads.txt             # Authorized ad sellers (50+ networks)
├── site.webmanifest        # PWA manifest
├── css/
│   ├── main.css            # Design system, layout, components
│   ├── animations.css      # Keyframes, reveal, scroll, marquee
│   └── responsive.css      # Media queries
├── js/
│   ├── main.js             # Core interactions (header, form, modal, tabs…)
│   └── animations.js       # Advanced effects (parallax, particles, magnetic…)
└── images/
    ├── logo.svg
    ├── favicon.png
    ├── og-image.png
    ├── hero-bg.png         # Hero background
    ├── icon-*.svg          # 32 SVG icons
    ├── app-*.png           # 6 app screenshots
    ├── avatar-*.png        # 6 team avatars
    ├── banner-*.png        # 4 section banners
    ├── illustration-*.png  # 4 illustrations
    └── hero-grid.svg       # Decorative grid
```

## Tech stack

- **HTML5** + semantic markup
- **CSS3** with custom properties, Grid, Flexbox, container queries
- **Vanilla JavaScript** (no frameworks, no build step)
- **SVG** for every icon, logo and decorative element
- **PNG** (programmatically generated with PIL) for hero/illustrations
- **JSON-LD** structured data for Google rich results
- **Open Graph** + **Twitter Card** metadata
- **Canonical**, **hreflang** and **robots** directives
- **PWA** web manifest for installable web app
- **WCAG 2.2 AA** accessibility targets

## Design language

- Dark, deep-navy palette with cyan-to-magenta gradients
- Tesla-inspired minimalism, but with rich motion
- Typography: system fonts, monospace for metadata
- Animations: 30+ keyframe animations, scroll reveals, hover effects
